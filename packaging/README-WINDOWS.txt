Movie Review Studio Stage 1 for Windows x64

Extract the entire ZIP, then double-click RUN_WINDOWS.bat or
MovieReviewStudio.exe. Keep the _internal folder next to the executable.
Python, Qt, FFmpeg and FFprobe are bundled.

FFmpeg-Source contains the exact FFmpeg and x264 source snapshots, their
licenses, and the build script used to compile the bundled GPL media tools.
Python package metadata and license files are included under _internal.
